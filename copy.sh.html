Magenta is now 64-bit

Magenta and Avalanche Kernel now target x86-64. Copy.sh's v86 emulator does not implement 64-bit long mode, so it cannot boot this release.

Use a 64-bit VirtualBox machine or QEMU with qemu-system-x86_64. Attach the ISO as boot media and the separate data disk for saved files.

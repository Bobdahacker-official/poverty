Get to know Magenta.

Magenta is the desktop distribution of Avalanche Kernel, an independent x86-64 operating system written in C and assembly.

Boot a desktop

  1. Download the Magenta ISO and the persistent data image.
  2. Create an x86-64 virtual machine and attach the ISO as its optical disk and the data image as an IDE disk.
  3. Enable a standard VGA display and boot from the optical disk. Choose Magenta in the boot menu.

With QEMU installed:

qemu-system-x86_64 -m 512 -boot d \
  -cdrom magenta.iso \
  -drive file=magenta-data.img,format=raw,if=ide \
  -nic user,model=e1000 \
  -device virtio-rng-pci,disable-modern=on

For a source build, clone the repository, install the tools listed in its README, then run make and make run.

Make yourself at home

Applications opens the searchable launcher. Click a dock icon to open or focus its app. Window controls minimize, maximize and close. Drag a header to move a window and its lower corner to resize it.

Settings → Appearance changes the palette, accent, background and glass opacity. Appearance is saved to the writable disk. The desktop scales its interface to the display. Right-click an application icon to add or remove its desktop shortcut.

Games

Ctrl+Y opens Games. Minesweeper offers Beginner, Intermediate and Expert fields. The first revealed square is safe. Right-click to flag a mine, or turn on Flag mode for touch. Click a revealed number to clear its neighbors once you have marked the surrounding mines.

In 2048, move with the arrow keys, W A S D, or the on-screen direction buttons. Matching tiles merge once per turn. U undoes a turn; R starts a new game. Best scores and minefield completion times are saved on disk.

Install an application

The developer SDK builds and signs .mgnta executables. In the browser desktop, choose Upload app in the noVNC toolbar and select a signed .mgnta.zip bundle. The upload page verifies the signature and shows the developer certificate’s SHA-256 fingerprint.

Open Packages. For a new developer, choose Trust uploaded signer after checking the fingerprint. Choose Install uploaded app. Open the resulting .mgnta executable in Files, or run it from Terminal.

For a hosted repository, pin its developer certificate with pkg trust or pkg trust-url, then fetch its manifest:

pkg trust-url https://packages.example.org /trust.der
pkg fetch https://packages.example.org /hello.mgnta.manifest
pkg query hello.mgnta
hello.mgnta
pkg remove hello.mgnta

The host and path are your repository’s own address. Signatures cover the manifest, including the executable’s SHA-256. Installation checks that hash before committing the executable and package record to disk.

Hardware and storage

Avalanche boots through BIOS or x86-64 UEFI. Firmware GOP supplies graphics on UEFI systems. Storage drivers cover ATA, AHCI, NVMe, transitional VirtIO block and USB mass storage through UHCI and xHCI. Ext4 volumes can use GPT or primary Linux MBR partitions.

Input includes PS/2 and USB HID keyboards and mice. Intel HDA provides analogue PCM output. Network drivers include E1000, RTL8139, PCnet and transitional VirtIO net. The memory manager supports machines with 32 GiB of RAM, with runtime memory discovery and mappings up to 64 GiB.

For the build, tests and code layout, read the repository documentation. Open a GitHub issue with the hardware model and reproduction steps to report a problem.

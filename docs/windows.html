NATIVE GUI SDK

Give your app
a window.

The desktop hosts application surfaces in movable, resizable windows. The app owns its pixels and receives input events. The compositor draws the header and pointer.

Open and draw

#include <magenta/app.h>
static uint32_t pixels[320 * 200];

struct av_gui_open window = {320, 200, "My app"};
int result = mg_window_open(&window);
struct av_gui_draw draw = {
    .width = 320, .height = 200, .stride = 320,
    .pixels = (uintptr_t)pixels
};
result = mg_window_draw(&draw);

Pixels are 32-bit RGB values; the compositor presents them as opaque pixels. The stride is measured in pixels. Set x, y, width and height to update a rectangle. Pixels point to the first source pixel for that rectangle. Calls copy the pixels into kernel-owned display memory before returning.

Surfaces range from 160×100 to 2048×1536 pixels. Each process owns one surface. The desktop fits it within its window while preserving its aspect ratio. API calls return negative error codes on failure.

Handle input and close

mg_window_event(&event) returns 1 with an event, 0 when the queue is empty, or a negative error code. Sleep between empty polls.

EventValues
AV_GUI_TEXTa: text byte, including Enter, Tab and Backspace
AV_GUI_KEYa: extended keyboard scan code
AV_GUI_MOUSEa: x, b: y in surface pixels; c: left, right and middle button bits
AV_GUI_QUITThe close control was selected

On quit, save the app's work, call mg_window_close() and return from main. The kernel also releases the surface when the process exits.

Build the example

mgnta build magenta-sdk/examples/window
sign magenta-sdk/examples/window/build/sdk-window.mgnta \
  --key keys/private.pem --certificate keys/certificate.pem \
  --version 1.0.0 --out signed

The window example draws a gradient, paints at the pointer when clicked, and exits through the desktop close control. Upload its signed bundle through Packages using the same installation flow as a terminal app.

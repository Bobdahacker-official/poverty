CLASSIC WORLDS

ClassiCube.
Built for Magenta.

ClassiCube 1.3.9 runs in a native Magenta window. The port uses the upstream C client, its software renderer, local world generator, launcher and input pipeline.

Get the ClassiCube disk

Download the Magenta ISO and the ClassiCube app disk. Extract the app disk and attach it as the writable IDE disk.

gzip -dk classicube-data.img.gz
qemu-system-x86_64 -m 512 -boot d -cdrom magenta.iso \
  -drive file=classicube-data.img,format=raw,if=ide \
  -nic user,model=e1000 -device virtio-rng-pci,disable-modern=on

Open a local world

Open classicube.mgnta from Files, or start it from Terminal. The launcher opens in its own desktop window. Create a local Classic world, then use the normal ClassiCube movement and block controls.

classicube.mgnta

The Magenta window handles mouse, keyboard, focus and close controls. Closing the app returns to Terminal.

Build from source

make classicube
make test-classicube

The port source downloads the pinned upstream source archive, verifies its SHA-256, builds a static x86-64 application, creates an ext4 app disk and checks it with e2fsck. It also packages the upstream license and credits. Learn more at classicube.net and the ClassiCube source repository.

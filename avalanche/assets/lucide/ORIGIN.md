Source: https://github.com/lucide-icons/lucide

Original SVG icons are preserved in Images/lucide at the repository root. ISC/Feather MIT notices are preserved beside both the sources and atlas. The native atlas rasterizes these nine icons at 48 pixels: terminal, folder-open, file-text, chart-column, globe, package, settings, layout-grid, power.

Visual research: https://github.com/vinceliuice/WhiteSur-gtk-theme and https://github.com/PapirusDevelopmentTeam/papirus-icon-theme informed gloss, spacing and icon hierarchy. Their theme implementation code is not incorporated.
